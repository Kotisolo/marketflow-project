# MarketFlow

MarketFlow is an independent software development project focused on marketing automation and advertising analytics.

## Project Overview

MarketFlow is being developed as a web application to help users connect advertising accounts, view campaign performance, and understand marketing results through a centralized dashboard.

## Google Ads API Intended Use

MarketFlow is intended to use the Google Ads API to:

- Connect authorized Google Ads accounts securely using Google OAuth 2.0.
- Retrieve information about accessible advertising accounts.
- Display campaign details and performance reports.
- Provide read-only analytics and reporting.

MarketFlow is currently under development and testing. The Google Ads integration is not intended to create, modify, or activate advertising campaigns or manage billing.

## Technology

- React and Vite frontend
- Java Spring Boot backend
- PostgreSQL database
- Google OAuth 2.0

## Project Status

Under active development. This repository currently serves as a public description of the project.
